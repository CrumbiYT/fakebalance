# Fake Balance Display (client-side, Fabric 1.21.11)
Changes how a balance line looks on YOUR OWN sidebar scoreboard. Nothing is sent to the server.

Commands (client-side):
- /fakebal                toggle on/off
- /fakebal set 16B        what the number is displayed as
- /fakebal label <regex>  text that appears before the number on your scoreboard line (default: money|balance|bal|cash|coins)

Build: ./gradlew build  ->  build/libs/fakebalance-1.0.0.jar
